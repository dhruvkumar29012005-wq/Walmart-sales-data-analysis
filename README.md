# Walmart Sales Data Analysis

## Overview
Walmart ke sales data ka analysis SQL (SSMS) use karke kiya hai. Isme 1000 transactions ka data hai - 3 branches, 3 cities ke.

## Dataset
- File: WalmartSalesData.csv
- Rows: 1000 Transactions
- Columns: Invoice ID, Branch, City, Customer Type, Gender, Product Line, Unit Price, Quantity, Tax, Total, Date, Time, Payment, Rating

## Tools Used
- SQL Server Management Studio (SSMS)
- SQL
- Excel / CSV

## Key Analysis Done
1. Sales by Branch & City - Kaunsi branch / city sabse zyada sales de rahi hai
2. Product Line Analysis - Kaunsa product sabse zyada bik raha hai aur sabse zyada revenue de raha hai
3. Customer Analysis - Member vs Normal customer, kaun zyada kharch kar raha hai
4. Payment Method - E-wallet, Cash, Credit Card me se sabse popular kaunsa hai
5. Time Analysis - Morning / Afternoon / Evening me kab sales sabse zyada hoti hai
6. Rating Analysis - Kaunsi branch / product line ko sabse acchi rating mili

## Key Findings
- Yangon branch ne sabse zyada sales generate ki
- Electronic accessories aur Fashion accessories top selling categories hai
- Member customers, Normal customers se zyada spend karte hai
- Afternoon time me sabse zyada sales hoti hai

## Files in this Repo
- WalmartSalesData.csv - Raw Dataset
- PROJECT NO.1.sql - Saari SQL Queries

## How to Run
1. SSMS me WalmartSalesData.csv import karo
2. PROJECT NO.1.sql wali file open karo aur run karo
